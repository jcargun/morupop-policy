택배냥 개인정보처리방침

택배냥: 고양이 길찾기 퍼즐 · com.morupop.parcelcat
운영 브랜드: MORUPOP Games · 시행일: 2026년 10월 4일

현재 Google Play 테스트에 배포된 0.2.9 버전에는 광고 SDK, 인앱 결제, 원격 분석·오류 보고 SDK가 없습니다. 광고 SDK가 없는 일반 release 빌드에도 아래의 기기 내 저장·지원 문의 설명이 적용됩니다.

광고 포함 업데이트 고지 초안: 개발 중인 0.2.10에는 별도의 선택형 광고 빌드를 준비하고 있습니다. 아직 실제 광고 버전을 Google Play에 배포한 것은 아닙니다. 아래 5번은 그 광고 빌드의 처리 내용을 설명하는 사전 고지이며, 실제 배포 전에 공개 방침과 Google Play 데이터 보안 정보를 함께 갱신합니다. Google 샘플 광고를 사용하는 개발·검증 빌드는 광고 수익을 발생시키지 않습니다.

데이터 삭제 방법과 문의

택배냥에는 회원가입이나 사용자 계정이 없습니다. 휴대폰 안의 게임 기록은 Android 설정 → 앱 → 택배냥 → 저장공간 → 데이터 삭제에서 지울 수 있습니다. 앱을 제거해도 기기 내 기록이 삭제됩니다. 기기별 메뉴 이름은 다를 수 있으며 삭제한 진행과 설정은 복원할 수 없습니다.

MORUPOP Games에 직접 보낸 문의나 첨부자료의 삭제는 아래 방법으로 요청할 수 있습니다.

  1. morupop.support@gmail.com으로 제목을 ‘택배냥 데이터 삭제 요청’으로 하여 이메일을 보내주세요.
  2. 가능하면 기존 문의를 보낸 이메일 주소를 사용하고 삭제할 문의의 날짜나 제목을 알려주세요. 비밀번호나 신분증은 보내지 마세요.
  3. 요청을 확인한 뒤 개발자가 보유한 해당 문의 이메일, 첨부 기록과 별도로 내려받은 첨부파일을 삭제하고 처리 결과를 회신합니다. 식별 정보가 부족하면 추가 확인을 요청할 수 있습니다.

일반 문의 자료는 문의 해결 후 90일 이내 삭제합니다. 삭제 요청은 이 기간이 지날 때까지 기다리지 않고 확인 후 지체 없이 처리합니다. 법령상 보관 의무가 있는 자료는 해당 기간 동안만 보관하며 해당하는 경우 보관 이유·대상·기간을 회신합니다. 개발자는 휴대폰 안의 게임 기록을 원격으로 삭제하거나 복원할 수 없습니다.

1. 기기에 저장하는 게임 정보

게임을 이어하기 위해 진행 상황, 단계별 별, 일일 지도 기록, 진행 중인 판과 되돌리기 기록, 도움말 확인 여부, 효과음·화면 효과·편지지 설정 등을 기기 안에 저장합니다. 앱 자체의 클라우드 동기화와 온라인 순위표는 제공하지 않습니다.

게임은 이름, 이메일 주소, 전화번호, 주소록, 사진, 마이크·카메라 정보나 정밀 위치 권한을 요청하지 않으며 게임 기록을 개발자 서버로 전송하지 않습니다. 광고 SDK가 없는 버전은 광고 식별자를 처리하지 않습니다. 광고 포함 빌드의 외부 SDK 처리 내용은 5번을 확인해 주세요. 광고 이용을 제외한 게임 기능은 인터넷 연결 없이 이용할 수 있습니다.

2. 저장과 삭제

Android 게임 기록은 앱 전용 저장 공간에 보관합니다. Android 백업과 기기 이전에 이 기록이 포함되지 않도록 설정되어 있습니다. 앱 삭제 또는 앱 데이터 삭제 전까지 저장되며, 삭제한 기록을 개발자가 복원하는 서비스는 없습니다.

웹 플레이의 기록은 해당 브라우저 저장 공간에 보관되며 브라우저의 사이트 데이터를 지우면 삭제됩니다. 이 방침의 Google Play 출시 대상은 Android 앱입니다.

3. 선택형 플레이테스트 기록

이용자가 설정에서 플레이테스트 기록을 직접 켠 경우에만 현재 실행의 단계 시작, 길 회전, 되돌리기, 힌트, 배달 실패·완료와 상대적인 경과 시간을 최대 500건 임시 기록합니다. 사용자 이름, 계정, 설치 식별자 등 개인 식별자를 기록하지 않습니다.

기록은 실행 중 메모리에만 보관하며 개발자에게 자동 전송하지 않습니다. 기록을 끄거나 앱 화면이 새로 시작되면 삭제됩니다. 같은 화면으로 복귀하는 단순한 백그라운드 이동만으로는 삭제되지 않을 수 있습니다.

이용자는 종료 전에 기록을 확인하고 직접 클립보드에 복사할 수 있습니다. 다른 앱에 붙여넣거나 개발자에게 전달할지는 이용자가 선택합니다. 전달한 내용은 해당 앱이나 서비스에서도 처리될 수 있습니다.

4. 직접 보내는 정보와 지원 문의

게임 기능은 저장한 게임 기록과 임시 플레이테스트 기록을 개발자나 외부 사업자에게 자동 제공하지 않습니다. 광고 포함 빌드의 SDK는 5번에 설명한 별도의 정보를 처리할 수 있습니다. 이용자가 지원 이메일로 직접 문의하면 발신 주소, 문의 내용, 이용자가 첨부한 자료를 문의 처리와 회신에 사용합니다.

문의 이메일과 첨부자료는 문의 해결 후 90일 이내 삭제합니다. 문의 대응을 위해 별도로 내려받은 첨부파일도 삭제 대상에 포함됩니다. 법령에 따라 보관해야 하는 경우에는 해당 기간 동안 필요한 정보만 보관합니다.

지원 이메일은 Google Gmail을 사용합니다. 이메일 서비스의 처리는 Google 개인정보처리방침을 따릅니다. 개인정보 문의와 삭제 요청은 morupop.support@gmail.com으로 접수합니다.

5. 선택형 광고 빌드의 정보 처리 — 배포 전 초안

광고 포함 빌드는 Google AdMob의 Google Mobile Ads SDK와 개인정보 선택을 위한 User Messaging Platform(UMP)을 사용합니다. Google은 광고 제공·분석·부정 이용 방지 등을 위해 IP 주소(대략적인 위치 추정에 사용 가능), 앱 실행·탭·동영상 시청 같은 상호작용 정보, 앱·SDK 성능과 오류 등 진단 정보, 기기·계정 관련 식별자를 수집·공유할 수 있습니다. 개발자가 자체 원격 분석 SDK를 사용하지 않는다는 설명이 Google 광고 SDK의 이러한 처리가 없다는 뜻은 아닙니다.

이 빌드는 Android 광고 ID 권한(AD_ID)을 제거하도록 구성합니다. 이는 광고 ID 수집을 막기 위한 설정이며, 앱 세트 ID 등 다른 식별자나 IP 주소의 처리까지 모두 막지는 않습니다. Google Mobile Ads SDK가 전송하는 이용자 정보에는 전송 구간 TLS 암호화가 적용됩니다. 상세 처리와 보관·삭제 관련 사항은 Google 개인정보처리방침 및 Google 광고 SDK 정보 처리 안내를 확인해 주세요. 개발자 문의 자료의 90일 보관 기준은 Google이 처리하는 광고 정보에는 적용되지 않습니다.

광고 기능을 처음 선택할 때 ‘13~15세’ 또는 ‘16세 이상’ 연령 구간을 선택하며, 선택은 휴대폰 안에 저장합니다. 생년월일이나 신분증을 요구하지 않습니다. 13~15세 또는 선택이 확인되지 않은 경우에는 보수적으로 동의 연령 미만 신호를 Google SDK에 전달하도록 준비합니다. 저장한 구간과 이 신호는 이용자 동의나 실제 나이 확인을 대신하지 않습니다. 광고 기능은 13세 이상을 대상으로 준비하며, 광고 콘텐츠 등급 상한은 G로 제한합니다.

실제 광고 요청 전에 UMP로 현재 개인정보 선택 상태를 갱신하고, 지역·계정 설정상 필요한 경우 Google의 개인정보 안내 화면을 표시합니다. UMP에서 광고 요청 가능 여부를 확인하기 전에는 광고 요청을 진행하지 않습니다. 개인정보 선택 변경이 필요한 이용자에게는 앱 설정의 ‘광고 개인정보 선택’ 메뉴를 제공합니다. 연령 구간은 광고 연령 설정에서 다시 선택할 수 있습니다. 개발용 샘플 광고 확인만으로 실제 지역별 동의 화면까지 검증한 것은 아닙니다.

모든 스테이지와 힌트는 광고 없이 무료로 이용할 수 있습니다. 광고는 이용자가 보상 버튼을 눌렀을 때 선택하여 시청하는 형태로 준비하며, 보상은 달빛 편지지 1개입니다. 광고 시청을 거절하거나 중간에 닫아도 게임 진행에 불이익을 주지 않습니다. 보상은 완료 확인 뒤 지급하며 이미 받은 영구 편지지를 위해 다시 광고를 요구하지 않습니다. 광고 서비스나 개인정보 안내를 불러올 수 없어도 게임을 계속 이용할 수 있습니다.

6. 개인정보처리방침 웹페이지

공개 방침 페이지는 GitHub Pages로 제공합니다. 페이지 방문 시 호스팅 제공자인 GitHub가 서비스 제공과 보안 등을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요. 이 페이지에는 광고나 방문자 분석 스크립트를 넣지 않습니다.

7. 변경과 연락처

광고나 원격 분석 등 정보 처리 기능을 추가하거나 변경하면 실제 동작에 맞게 이 방침과 Google Play 데이터 보안 정보를 갱신합니다.
